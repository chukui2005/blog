六、总结：RabbitMQ核心面试清单

  1. 四种Exchange：Direct/Topic/Fanout/Headers
  2. 消息不丢失：Confirm + 持久化 + 手动ACK
  3. 幂等性：唯一ID去重表 / 业务主键
  4. 延迟队列：TTL+死信 / 延迟交换机插件
  5. 死信队列：拒绝/过期/满 → DLX → DLQ → 处理
  6. 集群：Quorum Queue（Raft）替代镜像队列趋势
  7. 顺序：单Queue + 单Consumer
