四、@Conditional 条件装配（灵魂）

自动配置类并不是全量生效的。每个自动配置类上都有 @Conditional 注解，条件满足才生效。

4.1 常用 @Conditional

注解 判断条件
@ConditionalOnClass classpath 中有指定类
@ConditionalOnMissingClass classpath 中没有指定类
@ConditionalOnBean 容器中有指定 Bean
@ConditionalOnMissingBean 容器中没有指定 Bean
@ConditionalOnProperty 配置文件中有指定属性
@ConditionalOnResource classpath 中存在指定资源文件
@ConditionalOnWebApplication 当前是 Web 应用
@ConditionalOnExpression SpEL 表达式为 true
