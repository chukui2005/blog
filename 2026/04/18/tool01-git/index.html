五、回滚操作：reset / revert / checkout

命令 作用 是否动历史 适用
git reset –hard HEAD~1 移动分支指针，丢弃提交 ✅ 重写历史 本地未推送的提交
git revert 生成一个”反向提交” ❌ 新增提交 已推送的提交（公共分支）
git checkout – file 丢弃工作区修改 ❌ 撤销未暂存修改
git reset HEAD file 取消暂存 ❌ 撤销git add

面试一句话：reset 是”时光倒流”（本地用），revert 是”新增补丁抵消”（远程用）。
