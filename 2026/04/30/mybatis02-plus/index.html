MyBatis-Plus实战

核心知识点速览

知识点 要点
MP是什么 MyBatis增强工具，只做增强不做改变
核心能力 BaseMapper通用CRUD + 条件构造器 + 分页插件
常用注解 @TableName / @TableId / @TableField
条件构造器 QueryWrapper / LambdaQueryWrapper
分页插件 MybatisPlusInterceptor + Page
生产特性 逻辑删除 / 自动填充 / 乐观锁 / 代码生成器

一、MyBatis-Plus 是什么

能力 MyBatis MyBatis-Plus
单表CRUD 手写SQL ✅ 内置通用方法
条件查询 手写 ✅ 条件构造器
分页 插件/手写 ✅ 内置分页插件
逻辑删除 手写 ✅ 注解配置
自动填充 手写 ✅ MetaObjectHandler
复杂SQL XML XML（不冲突）

二、快速上手

2.1 核心依赖与配置

2.2 实体类与Mapper

2.3 BaseMapper 内置方法

方法 说明
insert(entity) 插入
deleteById / delete(wrapper) 删除
updateById / update(entity, wrapper) 更新
selectById / selectOne(wrapper) 单查
selectList(wrapper) 列表查询
selectPage(page, wrapper) 分页查询
selectCount(wrapper) 计数

三、条件构造器（Wrapper）

3.1 三种Wrapper对比

Wrapper 说明
QueryWrapper 普通条件构造（字符串列名，编译期不校验）
LambdaQueryWrapper Lambda列名，编译期类型安全，推荐
UpdateWrapper 更新专用，可set指定字段

3.2 常用查询

条件方法 SQL含义
eq / ne = / <>
gt / ge / lt / le > / >= / < / <=
like / likeLeft / likeRight LIKE %x% / %x / x%
between / notBetween BETWEEN
in / notIn IN
isNull / isNotNull IS NULL
and / or 逻辑组合

四、分页插件

原理：分页插件拦截 Executor，改写 SQL 为 SELECT COUNT(*) + LIMIT offset, size，通过 ThreadLocal 传递分页参数。注意 count 查询要快（避免大表全count）。

五、生产常用特性

5.1 逻辑删除

5.2 自动填充（创建/更新时间）

5.3 乐观锁（防并发覆盖）

5.4 代码生成器

六、MyBatis vs MyBatis-Plus 怎么选

场景 选择
单表CRUD为主、追求效率 MyBatis-Plus
SQL高度定制、复杂联查多 MyBatis + XML（MP同样支持）
新项目 直接用 MP（增强不改变，可退回原生）
老项目改造 可逐步引入，不冲突

七、面试重点清单

  1. 定位：只做增强不做改变，继承BaseMapper即得CRUD
  2. 常用注解：@TableName / @TableId / @TableField / @TableLogic / @Version
  3. Wrapper：LambdaQueryWrapper类型安全，eq/like/between/in/orderBy
  4. 分页：MybatisPlusInterceptor + Page，自动count+limit
  5. 逻辑删除：删除变UPDATE，查询自动过滤
  6. 自动填充：MetaObjectHandler，创建/更新时间免手写
  7. 乐观锁：@Version + 插件，防止并发覆盖
  8. 代码生成器：MyBatisX，脚手架秒出
