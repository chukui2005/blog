一、网关到底解决什么

没有网关的时候，每个服务都要自己处理这些：

七八个服务各写一遍，改一次规则要改八处。网关就是把这些横切关注点收拢到入口处统一处理。

顺带还有个好处：业务服务不用暴露公网，只开内网端口，安全边界清晰。

代价是：在 Gateway 里不能写阻塞代码（JDBC 查询、同步 HTTP 调用、Thread.sleep），一旦阻塞会拖死整个事件循环。
